# LYR M3.2 Design — Knowledge Explorer

**Status:** Proposed
**Stage:** M3.2 (the bridge between forming durable knowledge and forming cognition)
**Prerequisite:** M3.1 complete

---

## 1. Motivation

M3.1 solved *forming* durable knowledge: the system can determine what should become
durable, why, how the decision was verified, and how it traces to evidence.

But a user never interacts with **one** `JudgmentRecord`. Real collections hold
hundreds of semantic memories, dozens-to-hundreds of durable memories, years of
accumulated experience. The Judgment Explorer explains **one** decision extremely
well; it does not yet help a user explore an entire body of knowledge.

M3.2 introduces the first user-facing **knowledge exploration** experience.

---

## 2. Goal

Not to answer questions. Not to summarize. Rather:

> Let a user explore an entire knowledge space and gradually understand it.

Closer to **exploring Wikipedia** than chatting with an LLM.

---

## 3. Design principles

- **P1. Exploration before conversation.** Users browse; conversation is optional. Encourage curiosity, not prompting.
- **P2. Knowledge first.** The UI exposes *knowledge* — not prompts, agents, or chains.
- **P3. Progressive disclosure.** Start with large concepts; every click reveals more; never dump hundreds of memories at once.
- **P4. Everything remains explainable.** Every concept ultimately traces `Durable → Semantic → Source`. Nothing appears without provenance.

---

## 4. Initial domain

Version 1 deliberately focuses on **one** domain: a **Book** (memoir, biography,
technical book, history, philosophy). Intentionally much narrower than "all
knowledge."

---

## 5. User experience

The landing becomes: **Choose a Book → Explore.** Instead of a search box, the user
first sees entry points:

**People · Ideas · Events · Places · Themes · Lessons**

Each is a doorway into the knowledge.

---

## 6. Exploration

Always moves from high-level concepts *toward* evidence. E.g.:

```
People → Ye Wenjie → Timeline → Related Events → Durable Memories → Source Evidence
Themes → Trust → related durable memories → supporting evidence → conflicting evidence
```

---

## 7. Durable organization

The first **organization** layer over durable memories — *not* cognition, only
navigation:

```
120 Durable Memories → grouped → Family · Science · Politics · Morality · Survival
```

Groups exist **only for navigation**. They are not new knowledge. They do **not**
become `Node`s.

---

## 8. Judgment integration

Every durable memory stays clickable; selecting one opens the existing **Judgment
Explorer**:

```
Knowledge Explorer → Durable Memory → Judgment Explorer
```

The M3.1 Judgment Explorer becomes a **developer-level drill-down**, not the primary
interface.

---

## 9. Non-goals

Cognition · theory formation · long-term reasoning · agent planning · chat ·
recommendations · memory editing. The goal is *understanding existing knowledge.*

---

## 10. Success criteria

A first-time user can, **without asking a single question**: understand what the book
is about; discover important people; discover important ideas; understand how ideas
evolved; inspect why any durable memory exists; and trace any conclusion back to
evidence.

---

## 11. Why this comes before M4

M4 asks *how do durable memories become cognition?* M3.2 asks *how do humans navigate
durable memories?* Until users can comfortably explore durable knowledge, there is no
practical way to evaluate whether higher-level cognition is actually useful. M3.2
provides both the first public demonstration of LYR **and** the foundation for
evaluating future Cognitive layers.

It also protects M4: building a Knowledge Explorer first forces the question *"can a
real user understand what this new layer adds?"* — a feedback loop that will make the
eventual Cognitive layer much stronger, instead of abstractions only the author can
inspect.

---

## 12. Future direction

Once durable knowledge is naturally explorable:

```
Book → Semantic → Durable → Knowledge Explorer → Cognition → Cognitive Explorer
```

M4 then no longer generates isolated theories; cognition emerges as an additional
**explorable layer** built on top of durable knowledge.
