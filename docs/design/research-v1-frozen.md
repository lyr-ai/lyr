# Research v1 — Frozen

> **Research v1 is frozen with a located frontier, not a completed Knowledge Claim Layer.**

**Date:** 2026-08-03. This is a deliberate phase change from Research to Product, made while the
backend is entering *optimization* rather than *discovery*. It is an honest closure, not a retreat.
Reopening the backend requires a trigger below — not a better idea.

## Established (holds)

- **Source → Semantic → Durable** substrate, with provenance and identity/history.
- A **generic document parser** (novel / docs / markdown, chosen by manifest, never by title).
- **Entity resolver** improvements proven across languages and technical corpora (CJK name-expansion;
  digit-only version discrimination; person/service/file/model type-gating).
- The **auditable identification protocol** (the identifiability paper, theory-frozen).
- **Scoped, evidenced, status-bearing claims** as the working representation of Knowledge —
  converged on across four independent worlds (DeepSeek, P&P, Elizabeth, Kimi).
- A **deterministic abstention baseline** that is executable *within a closed predicate range*
  (Part A: 0/10 fabrication acceptance, 5/5 retention).

## Not yet established (open)

- A **generic claim proposer.**
- **Generic open-relation grounding** (the Part B frontier).
- A **production-ready Knowledge Claim Layer.**
- **Scalable knowledge synthesis.**
- **Automatic theme / state formation.**
- **Reliable cross-corpus concept identity** (`MLA@DeepSeek` vs `MLA@Kimi`).

Naming any of these "done" would overstate; erasing the Established list would understate. Both are
avoided.

## Reopen triggers (only these three)

1. **A real product unsupported claim.** The Explorer, on real data or in real user interaction,
   commits a claim with no supporting evidence, and the current mechanism cannot intercept it.
2. **A product-needed relation that cannot be expressed or verified.** A high-value interaction
   repeatedly needs `X uses Y` / `X replaces Y` / `X improves Y` / `X caused Y`, and generic relation
   grounding becomes a *product* blocker — not a lab-imagined one.
3. **External evidence.** An independent reviewer finds a formal flaw; a user case produces an
   inexpressible claim; a new benchmark shows the scoped-claim substrate insufficient; or a human /
   external system running the protocol gets systematically different results.

**Not** reopen triggers: a more elegant schema; wanting to add predicates; a Kimi page looking thin;
a feeling the Knowledge Layer is "almost there"; making a paper more complete.

## Deferred research frontier

    Generic relation grounding over an open predicate space

Filed with its witness (`witness-partb-generic-relation-grounding.md`). Not deleted, not continued.
When the product genuinely hits it, it will not need to be rediscovered — and until then it will not
pull the project into a new long research program.

## What happens next (6–8 weeks): Explorer only

The goal is no longer to *prove* a Knowledge Layer. It is to let real users get, through the **existing
backend**, an experience clearly different from RAG. Priorities:

1. Multi-case Explorer.
2. Source / concept / entity / claim / evidence navigation.
3. The real knowledge spaces of DeepSeek and 红楼梦.
4. Jumping from an object to its related events, relationships, and evidence.
5. Simple grounded conversation.
6. Collecting real questions and real failures.

Only a product-surfaced reopen trigger returns us to backend research.
