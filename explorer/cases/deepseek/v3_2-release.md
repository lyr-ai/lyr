# DeepSeek-V3.2 Release Notes (2025/12/01)

## Models Released

- **DeepSeek-V3.2** — the official successor to DeepSeek-V3.2-Exp, available on
  App, Web, and API platforms.
- **DeepSeek-V3.2-Speciale** — an advanced reasoning variant, currently API-only
  without tool-use support.

## Reasoning Performance

DeepSeek-V3.2 offers a balanced trade-off of inference quality vs. length at
GPT-5 performance levels. DeepSeek-V3.2-Speciale is positioned to rival
Gemini-3.0-Pro with maxed-out reasoning capabilities, and achieved gold-level
results in IMO, CMO, ICPC World Finals, and IOI 2025.

## Agent Training

The release highlights a new massive agent training data synthesis method
covering 1,800+ environments and 85k+ complex instructions. DeepSeek-V3.2
introduces direct integration of thinking into tool-use workflows, supporting
tool-calling in both thinking and non-thinking modes.

## API

DeepSeek-V3.2 maintains the same usage pattern as its predecessor
DeepSeek-V3.2-Exp, with added thinking-in-tool-use support.
DeepSeek-V3.2-Speciale is available via a temporary endpoint until December 15th,
2025, with pricing identical to V3.2. Both models are released open-source via
Hugging Face repositories with accompanying technical documentation.
